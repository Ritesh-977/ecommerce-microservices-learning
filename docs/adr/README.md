# Architecture Decision Records (ADRs)

This folder records significant technical and architectural decisions for the project.

## Process

- Create a new ADR for decisions that affect structure, contracts, consistency, tooling, or cross-cutting behavior.
- Keep ADRs short: context, decision, consequences (and alternatives considered when useful).
- Number sequentially: `0001-...`, `0002-...`
- ADRs are immutable records of decisions; if a decision changes, add a new ADR that supersedes the old one.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated
